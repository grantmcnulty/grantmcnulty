### Building with AI

I build in Claude and GPT every day with my own team of AI agents. Daily tools: Claude Code, Claude Cowork, ChatGPT and MCP.

- **[grantmcnulty.com](https://grantmcnulty.com)**: this site and my CV, built with Claude Code. One content file generates the website, the web CV and the PDF. Visitors book calls through a small API on Cloudflare that reads my Google Calendar's free and busy times and sends a Google Meet invitation, with bot protection and cookie-free analytics.
- **Fact Checker MCP**: a local MCP server with 16 tools that Claude uses to check work before it goes out. It pulls the checkable claims from a document, fetches every cited source itself, grades each claim from A1 to D4 on an evidence standard, and keeps an append-only ledger with a history line on every change.
- **Agent fleet**: scheduled agents running on my own machine: a daily brief, a weekly look-ahead and a Friday wrap, plus nightly quality checks, snapshots and backups across my workspace.
- **Personal OS**: the capabilities above evolved into an integrated system, from ROI worksheets to value model to business case, and from outside-in points of view to personalised campaign execution. [A first look is on my website.](https://grantmcnulty.com/os/)
